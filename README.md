# Конструктор расписания

Тестовое задание: интерфейс для составления университетского расписания. Пользователь распределяет занятия по дням и временным слотам с помощью drag-and-drop, а приложение проверяет конфликты.

## Запуск

Нужны Node.js 22 LTS версии 22.13.0 или выше и npm. После клонирования выполните в папке проекта:

```bash
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

Сборка и локальный просмотр production-версии:

```bash
npm run build
npm run preview
```

## Что реализовано

- Создание занятия перетаскиванием секции в расписание.
- Перенос существующего занятия на другой день или время и копирование в выбранный слот.
- Выбор и изменение преподавателя и аудитории, автоматический подбор подходящей свободной аудитории.
- Удаление через перетаскивание в зону удаления или из редактора занятия.
- Несколько занятий в одной ячейке, если они не конфликтуют.
- Поиск секций, фильтры расписания по преподавателю и аудитории, счётчики распределённых занятий.
- Проверка конфликтов с объяснением причины и подсветкой допустимых и недопустимых слотов.
- Сохранение расписания после перезагрузки и сброс к исходным данным.
- Адаптивный интерфейс и touch DnD. На узких экранах расписание отображается по выбранному дню.

## Проверки конфликтов

Создание, перенос, редактирование и копирование запрещены, если:

- преподаватель уже занят в выбранном слоте;
- аудитория уже занята;
- вместимость аудитории меньше количества студентов в секции;
- преподаватель недоступен в выбранное время;
- у секции уже есть занятие в этом слоте.

## Архитектура

- `src/components` - интерфейс и элементы drag-and-drop.
- `src/domain` - проверка расписания и подбор аудитории.
- `src/data` - исходные mock-данные и типы.
- `src/utils` - сохранение и восстановление расписания через localStorage.

Правила проверки конфликтов вынесены из React-компонентов в domain-слой и используются при проверке слотов и сохранении занятий.

## Стек

React, TypeScript, Vite, dnd-kit.
